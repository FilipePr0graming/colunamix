# UI Rules

Regras visuais obrigatorias:

- Nao pode parecer template de IA.
- Nao pode parecer Linktree generico.
- Nao pode parecer SaaS comum.
- Nao usar emojis.
- Nao usar icones grandes genericos.
- Nao usar gradiente colorido demais.
- Nao usar excesso de texto.
- Nao deixar cards todos iguais.
- Usar bordas finas, blur, shadow suave, grain e microinteracoes.
- Mobile precisa ser excelente.
- Hover precisa ser perceptivel no desktop.
